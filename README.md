# Libri

Lightweight enchantment overhaul with unique enchantments, deep customization, and balanced progression.

## Enchantments

| Enchantment | Effect |
|-------------|--------|
| **Eternity** | Never lose durability |
| **Telekinesis** | Items go directly to your inventory |
| **Phoenix** | Slowly repairs items over time |
| **Sacrifice** | Converts mob drops into XP, scales with Looting |
| **Swift Strike** | Increases attack speed |
| **Smelting Speed** | Speeds up furnace smelting per level |
| **Fuel Efficiency** | Increases fuel burn time per level |

## Customization

- Adjustable anvil level cap (remove or keep)
- Adjustable maximum enchantment level (1–10000)
- Fully configurable via ModMenu + Cloth Config
- Server and singleplayer friendly

## Requirements

- Fabric Loader >=0.16.0
- Minecraft 1.21.1
- Fabric API
- Cloth Config >=15.0.0
